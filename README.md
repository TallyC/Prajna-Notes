# 金剛經修行工具

用手機或電腦逐分閱讀《金剛經》、練習誦讀，並記錄自己的理解與日常實踐。

## 如何使用

| 入口 | 用途 |
| --- | --- |
| 目 | 查看三十二分目錄，跳到想讀的經文。 |
| 讀 | 依科判閱讀經文、法義與梵文，查閱三家的讀經指導。 |
| 誦 | 分卡讀誦，搭配遮蔽或挖空練習。 |
| 布施 | 從財施、法施、無畏施的日常例子中自行抽卡；可以做一件力所能及的事，也可以只讀卡片，不必每日完成。 |
| 持行 | 記下讀誦心得、疑問與實踐，可匯出與匯入備份。 |
| 金剛藝藏 | 瀏覽經卷、書法、石刻、器物、當代創作、音樂與漫畫圖卡；並連到原有漫畫、圖卡與桌布頁。 |
| 參考、說明 | 查閱經文、講記、影音、講義及各工具的操作步驟。 |

底部導覽可回首頁、搜尋或調整閱讀設定。讀經位置、誦讀進度、閱讀設定和持行紀錄保存在使用的瀏覽器。換裝置前，可使用「持行」的備份與「誦」的進度同步碼。

## 下載與自行修改

原始程式公開在 [GitHub 儲存庫](https://github.com/TallyC/Prajna-Notes)。使用者可在儲存庫頁面選「Code」→「Download ZIP」下載完整網站，再自行修改與使用。若想維護自己的線上版本，可先 Fork 儲存庫，再依 GitHub Pages 的方式發布。

## 網站入口

- [金剛經修行工具 · GitHub Pages](https://tallyc.github.io/Prajna-Notes/)
- [金剛藝藏](https://tallyc.github.io/Prajna-Notes/collection.html)：以可見作品與簡介呈現經典如何進入生活，點選後閱讀深入說明。\n- [金剛經漫畫集](https://tallyc.github.io/Prajna-Notes/comics.html)：依果慨法師《金剛經：現代生活的覺醒導引》七集講座整理，逐頁閱讀共 33 頁。

## 經文與參考資料

經文底本、講義與書籍解說的來源，可在網站的「讀」及「參考」查閱。「讀」頁下方的「經文校對」提供三十二分起句、對照行號與異文。布施小卡是日常情境轉譯，典籍線索列在「布施」頁，並非經文逐句改寫。
